# 姚广孝 · 跳过（P0 原型）

开屏广告「跳过」按钮自动点击器。**只点击，不屏蔽、不注入手势、不联网。**

## 这一版做了什么

- 一条规则：窗口切换后 3 秒内，查找文本含「跳过 / 跳过广告 / 关闭广告 / Skip」的控件，点击它（或其可点击父节点）。
- 打分选择：优先屏幕上方 35%、偏右的、小尺寸的按钮，避免点到广告主体。
- 安全闸门：同一包名 3 秒冷却、单窗口最多 2 次、金融/支付/政务/系统界面永不动作。
- 全部命中写日志（时间、包名、命中文本、结果），最多 300 条，界面显示最近 40 条。

## 安装与开启

1. 安装 `姚广孝跳过_v0.1.0-p0.apk`（debug 签名，需允许「安装未知来源应用」）。
2. 打开 App → 「① 打开系统无障碍设置」→ 在「已下载的应用」里找到「姚广孝 · 跳过」→ 打开。
3. 回到 App，状态应显示绿色「无障碍服务已开启 ✅」。

## 怎么测（P0 只需要 3 个 App）

1. 默认模式是「除金融/系统外全部生效」，先不用填白名单。
2. 依次冷启动 3 个带开屏广告的 App（建议：抖音、淘宝、知乎这类），每个等开屏出现。
3. 回到本 App 看日志：
   - 有 `命中「跳过」| 已点击` → 成功；
   - 有 `命中「…」| 点击未生效` → 找到了但点不动（父节点不可点，需要 P1 改点击策略）；
   - 完全没有记录 → 无障碍没读到节点（多半是自绘界面），或窗口事件没触发。

把日志截图或文本发回来，就能判断下一步是继续做规则引擎，还是改走截图识别。

## 已知限制（P0 故意不做）

- 不做坐标兜底点击：宁可漏跳，不误点。
- Flutter / Skia 自绘、WebView 内的「跳过」可能读不到节点。
- 不做保活对抗、不做伪装、不隐藏服务，HyperOS 请在「电池 → 应用」里设为「不限制」。
