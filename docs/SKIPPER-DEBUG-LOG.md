# 调试日志怎么用（真机排查）

## 打开

1. 「姚广孝 · 跳过」→ 设置 → 调试卡片
2. 打开「调试日志」开关（同一张卡点进去就是日志页）
3. 回到桌面，去打开一个**有开屏广告**的 App，等 3~5 秒
4. 回到「设置 → 调试」，点右上「复制全部」，粘贴发我

## 日志长什么样

```
15:19:02.431 服务已连接
15:19:02.432 设置更新 enabled=true 窗口=3000ms 冷却=3000ms 上限=2
15:19:05.110 事件 pkg=com.example.news cls=...SplashActivity 节点=87 屏=1080x2400
15:19:05.111   命中 label="跳过 5" 分数=0.96 规则=general.skip 区域=[880,150,1010,230]
15:19:05.512 事件 pkg=com.example.news cls=...MainActivity 节点=214 屏=1080x2400
15:19:05.513   未命中 原因=超过工作窗口，本界面不再动作 最高分=0.00 规则=-
```

没命中时那行会给中文原因，六种之一：

| 原因 | 意思 | 怎么处理 |
|---|---|---|
| 包名在黑名单里 | 金融/支付/政务/系统类，规则主动不动 | 正常，不要点 |
| 超过工作窗口 | 窗口打开 3 秒后才出现按钮 | 调大「工作窗口」 |
| 本界面已点满次数 | 一个界面最多点 2 次 | 正常 |
| 冷却中 | 两次点击间隔 <3 秒 | 正常 |
| 没有候选 | 文字/位置/尺寸/可点性任一不满足 | 把日志发我，看 label 和区域 |
| 有候选但分数不够 | 看着像但不是 | 把日志发我 |

## 边界

- 只存内存，最多 240 行，最新的在最前面；关掉开关就不再写
- 不落盘、不上传、不含账号内容，只有包名、控件文字、坐标、判定结果
- 杀进程即清空；要留存就先复制
